# 🌌 About Codex l

Codex l is a modern 3D creation and animation engine  
inspired by professional tools like Blender —  
but redesigned with a clean architecture and modular system.

It provides:

- 🎬 Advanced Animation System
- ✨ Real-Time Visual Effects
- 💡 Modern Lighting Engine
- 🎥 Camera System
- 🧠 Node-Based Extensions (planned)
- 🚀 High Performance Core

Codex l is built for creators, developers, and innovators.

---

# 🎞 Features

## 🎬 Animation System

- Timeline Editor
- Keyframe Interpolation
- Rigging Support
- Skeletal Animation
- Curve Editor (planned)

## ✨ Effects System

- Particle Engine
- Custom Shader System
- Dynamic Lighting
- Post-Processing Effects
- Bloom / Motion Blur (planned)

## 🧩 Modular Architecture

Everything is separated into:

- Core Engine
- Animation Module
- Effects Module
- UI Editor
- Utilities

---

# 🏗 Architecture

Codex l uses a layered system:

Core Engine → Scene Graph → Renderer  
Animation Engine → Timeline → Keyframes  
Effects Engine → Particles → Shaders → PostFX  

Designed for:

- Scalability
- Maintainability
- Performance
- Clean Extensions
